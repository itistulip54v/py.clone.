# Py.Clone

**Py.Clone** is a simple Python-based demo project created to practice programming fundamentals and version control with Git.  
It represents one of my early steps into coding, where I experimented with writing Python scripts and managing them using GitHub.

<br>

**Author** – Tulip

---

## 📖 Project Overview
The purpose of this repository is to:
- Explore the basics of Python programming.
- Practice cloning, committing, and pushing code using Git.
- Understand how repositories can be used to organize and share code.

This project is intentionally minimal, serving as a sandbox for learning and experimentation.

---

## 🛠️ Technologies Used
- **Python** – For writing simple scripts and testing logic.
- **Git** – For version control and tracking changes.
- **GitHub** – For hosting the repository online.
